# 🐍 Snake Premium - Python + Pygame

Projeto desenvolvido em Python utilizando a biblioteca Pygame, recriando o clássico jogo da cobrinha com melhorias visuais, sistema de menu e múltiplas comidas.

---

# 📚 Objetivo do Projeto

Este projeto foi criado com foco educacional para praticar:

- Lógica de programação
- Estruturas de repetição
- Manipulação de listas
- Eventos do teclado
- Interface gráfica com Pygame
- Organização de código em funções
- Desenvolvimento de jogos 2D

---

# 🎮 Funcionalidades

✅ Tela inicial interativa  
✅ Escolha da quantidade de comidas  
✅ Cobra colorida estilo rainbow  
✅ Sistema de pontuação  
✅ Barra superior de HUD  
✅ Fundo quadriculado  
✅ Comidas em formato circular  
✅ Tela de Game Over  
✅ Opção de jogar novamente  
✅ Controle por teclado  

---

# 🖼️ Interface do Jogo

O jogo possui:

- Fundo verde claro
- Grade visual quadriculada
- Barra superior cinza para informações
- Cobra multicolorida
- Sistema visual mais moderno

---

# 🕹️ Controles

| Tecla | Função |
|------|------|
| ⬆️ | Mover para cima |
| ⬇️ | Mover para baixo |
| ⬅️ | Mover para esquerda |
| ➡️ | Mover para direita |
| R | Reiniciar jogo |
| ESC | Fechar jogo |

# 📦 Instalação

## 1. Clone o repositório

```bash
git clone https://github.com/seu-usuario/snake-premium.git
```

---

## 2. Entre na pasta

```bash
cd snake-premium
```

---

## 3. Instale o Pygame

```bash
pip install pygame
```

---

## 4. Execute o projeto

```bash
python main.py
```
